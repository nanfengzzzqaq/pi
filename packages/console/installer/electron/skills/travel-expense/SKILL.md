# 差旅费用报销自动填报（易快报 / 合思）

用户给出飞书审批链接（app.ekuaibao.com，含 accessToken）时使用本技能。
核心原则：**只填表 + 存草稿，绝不点击“提交送审”，绝不删除单据。**

## 开始前需要向用户确认的信息

1. 报销链接（用户消息里通常已给出；没有就向用户要）。
2. 关联哪条出差申请（默认按用户说的行程匹配标题，如“常州”）。
3. 票据文件：每程火车票（铁路电子客票 OFD 或含 OFD/PDF 的压缩包）+ 同一张票的查验截图；多天出差还要住宿发票。缺少就明确向用户索要文件，拿到前不要动费用明细。

## 第一步：解析票据附件

用户发来的票据附件（.ofd 或 .zip）**先调用 `travel_read_invoices` 一次性解析**，直接得到
车次、起止站、日期、席别、票价、乘车人、发票号和建议上传的发票文件路径。
不要自己用 bash/powershell 手工解压解析。查验截图（图片）不需要解析，留作上传附件。

## 页面稳定锚点（data-testid）

- 关联申请：`field-expenseLink-select`
- 报销说明输入框：`field-text-u_事由`
- 费用明细“添加”：`field-expenseDetail-add`
- 存为草稿：`flexable-button-edit`
- **提交送审：`flexable-button-submit`——任何情况下都不许点击**
- 其余字段用 browser_snapshot 的 ref 或可见文字定位。

## 标准流程

1. `browser_navigate` 打开用户给的报销链接，`browser_wait` 等出现“差旅费用报销单”。
2. 点击 `field-expenseLink-select` 打开关联申请弹窗：用搜索框输入申请标题关键词（如“常州”），勾选匹配的申请（radio），点“确认”。
   - 选择前可点该申请的“详情”查看事由、费用性质、起止日期、城市，记录下来。
   - 关联成功后“申请单中的差旅起止日期”会自动带出；把它作为后续一切日期的依据。
3. 核对自动带出的字段（正常不用动）：所属公司=赛昇信息技术研究院江苏有限公司、提交人=苏爱健、报销日期=当天、申请人部门与费用所属部门=工业信息安全组。
   - 部门若为空：两个字段都按 赛昇信息技术研究院江苏有限公司 → 政策支撑部 → 工业信息安全组 逐级选择，且两处保持一致。
4. 填“报销说明”：写入关联申请的事由（如“常州业务拓展”），输入框 `field-text-u_事由`。
5. “驻地”：点开“选择城市”级联框，依次选 江苏省 → 南京市。**不要选“市辖区/市区”一类节点。**
6. “费用性质”：与关联的出差申请保持一致。先看申请详情里的费用性质（两种：部门费用 / 项目费用），当前值不对就点开下拉切换。
7. “关联项目”、“核销借款”、“是否为多收款人”：一律不处理。
8. “支付信息”：点“请选择支付信息”，选择收款人 **苏爱健**。
9. 生成费用明细计划：调用 `travel_plan_details`，传入申请起止日期、逐程车票（出发/到达城市、日期、席别、金额——全部来自第一步解析结果）、住宿费（仅多天出差）。
   - 判断规则：当天往返（起止同一天）只有 城市交通费 + 出差补助；多天出差为 城市交通费 + 住宿费 + 出差补助。
10. 逐条添加费用明细：点 `field-expenseDetail-add` → 在“添加明细”弹窗里先选费用类型，再按计划填字段：
    - **城市交通费**：费用类型选 火车/高铁；起止日期、出发/到达城市与出差申请一致；席别、金额与车票一致；每程一条（往返各一条）。
    - **住宿费**：金额与住宿发票一致，起止日期为入住~离店（或与申请一致）。
    - **出差补助**：补助类型固定选 **其他省份**；起止日期与申请一致；金额由系统按 180 元/天自动核算，不要手改。
    - 弹窗内字段每次都要重新 browser_snapshot 找 ref，不要沿用上一条的。
11. 上传票据：在表单顶部“附件”区，用 `browser_upload` 上传发票文件（用第一步解析给出的上传路径，通常为压缩包内的 PDF）和查验截图。文件路径由用户提供，一次传不完就分批。
12. 复查：browser_snapshot 确认必填（红 *）字段都有值、费用明细条数与计划一致、“支付金额”已由系统核算。
13. 点击 **存为草稿**（`flexable-button-edit`）。出现成功提示后向用户汇报：草稿已保存、填了哪些明细、金额合计、还缺什么（如未传的附件）。

## 红线

- 绝不点击 `flexable-button-submit`（提交送审）。
- 绝不点击“删除单据”。
- 金额与票据不一致、必填项拿不准、申请匹配有歧义时：停下来问用户，不要猜。
- 页面结构变化导致找不到锚点时：browser_snapshot 重新定位；连续失败就如实告知用户卡在哪一步。
- 如果工具列表里缺少 browser_click / browser_type / browser_upload（本轮没有页面交互工具），
  请用户在消息里带上“报销”或“差旅”等字样重新发送一次需求即可重新加载工具，不要尝试绕过。
